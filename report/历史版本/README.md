## 为什么保留而不是删掉

三个版本之间的差异全部来自**策略口径的变更**，不是排版调整：

- v3 → v4：只补课程要求的内容，数字未动
- v4 → v5：闸门从单向改双向，**所有指标都变了**（年化 +1.2pct、回撤 +0.2pct、Calmar +0.15）
- v5 → v6：只加一节展示层，数字未动

如果有人引用过早期版本里的 7.20% / 1.14，看到这里的对照就知道那是 v4 及以前的口径，
不是算错了。这也是保留它们的唯一理由。
